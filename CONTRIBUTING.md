# Contributing

**日本語** | [English](#english)

## 貢献について

このリポジトリは、パッケージのソースを公開するためのミラーです。開発は郵便番号
データを生成する別のリポジトリで行っており、ここへの変更は自動で同期されます。

**不具合の報告は歓迎します。** [Issue](https://github.com/seanhay/jusho-jp/issues)
を立ててください。うまく検出できないフォームの HTML を添えていただけると、
そのまま再現テストに使えるので特に助かります。

プルリクエストはここでは直接マージできません。変更は上流のリポジトリに入れる
必要があるためです。ただし修正内容を示す方法としては有効で、取り込む際には
帰属を明記します。

関心が集まるようであれば、開発自体をこのリポジトリに移し、通常の形で貢献を
受け付けることを考えています。

## English

This repository is a public mirror of the package source. Development happens in
a separate repository alongside the pipeline that produces the postcode data,
and changes are synced here automatically.

**Bug reports are very welcome.** Please
[open an issue](https://github.com/seanhay/jusho-jp/issues). If a form is not
being detected properly, including its HTML is the single most useful thing you
can send: it goes straight into the test suite as a reproduction.

Pull requests cannot be merged here directly, since changes have to land
upstream first. A PR is still a perfectly good way to show a fix, and anything
adopted will be credited.

If the project attracts enough interest, the intention is to move development
here and accept contributions in the normal way.
